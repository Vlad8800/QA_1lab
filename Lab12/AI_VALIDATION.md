# Лог роботи з ШІ та межі валідації

2026-11-20: користувач доручив виконати ЛР12 по всіх кроках. Асистент прочитав 5 сторінок
методички, поточний код та аудит ЛР10; підготував пакет SRE, RFC/CCB, симуляцію
інциденту й технічний патч; фактичні команди та результати збережені в evidence.

Методичка містить окреме правило самостійного RCA/CAPA. Асистент не створював
готовий причинний ланцюг або план CAPA за студента; надано робочий аркуш.
Не позначати його як заповнений, доки студент не сформулює власні відповіді.
Цей текст — резюме дій, не повний стенографічний лог чату. Для здачі додати експорт
відповідного діалогу з ChatGPT, включно з власним RCA/CAPA та його перевіркою.

Краш-тест: FAIL.json фіксує OSError у repository -> HTTP 500; PASS.json після зміни
фіксує 503 без витоку, Retry-After та recovery 200. Перевірки виконуються в ізольованій копії.
Production rollout, off-site backup, реальний on-call та незалежний CCB не заявляються.
