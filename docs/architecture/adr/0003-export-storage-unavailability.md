# ADR-0003 — контрольована недоступність сховища

Статус: Accepted for isolated lab experiment. Контекст: repository може підняти OSError.
Рішення: на HTTP boundary повернути 503 і Retry-After=30; не повертати текст винятку,
не замінювати невідомі дані порожнім успішним export. Авторизація залишається до читання.
Альтернатива: глобальний fallback 200 відхилено через неправдиву повноту даних.
Наслідки: контрольована деградація полегшує retry, але не покращує availability SLI сама по собі.
Таймаути й інші типи помилок потребують типізованого adapter exception у майбутньому.
