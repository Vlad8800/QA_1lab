# Кущ архітектурних рішень

Дата початку реєстру: **15.11.2026**. [SDD](../../sdd.md), [ISD](../../isd.md), [матриця аудиторій](../../audience-matrix.md).

| Номер | Рішення | Статус | Область |
| --- | --- | --- | --- |
| [0001](0001-demo-in-memory-boundary.md) | Зберегти in-memory storage лише для навчального baseline | Accepted | Runtime, state, RTO/RPO |
| [0002](0002-immutable-shipping-contracts.md) | Зберегти frozen контракти доставки | Accepted | Доменний контракт і тестованість |

Залежність: ADR-0001 задає межу застосування всього baseline; ADR-0002 фіксує рішення всередині цієї межі. Незмінні DTO не виправляють неперсистентність пам’яті; production storage вимагатиме окремого рішення.

Рішення датовані сьогоднішнім вибором зберегти наявний підхід. Історичні commit SHA в контексті — докази попередньої реалізації, а не заднім числом установлена дата ADR. Статуси lifecycle: Proposed → Accepted → Deprecated або Superseded. Якщо рішення змінюється, створити новий номер і явно вказати `Supersedes`; у старому змінити лише lifecycle-метадані та посилання на наступника. Старі альтернативи й наслідки не переписувати під новий результат.
