# INC-001 — недоступність legacy export repository

Тип: контрольована локальна симуляція, не реальна аварія користувачів.
SEV-2: export недоступний для авторизованого суб'єкта, решта API не вимикалася.
Виявлення: ручний fault-injection, а не спрацювання зовнішнього Grafana.
Часова база UTC, точність до мікросекунд, усі події припали на одну хвилину;
штучні хвилини очікування не додавалися.

| UTC | Подія |
| --- | --- |
| 2026-11-20T20:18:46.315818+00:00 | baseline probe |
| 2026-11-20T20:18:46.477251+00:00 | block repository reads using OSError injection |
| 2026-11-20T20:18:47.133690+00:00 | fault observed; no automatic restart of live API |
| 2026-11-20T20:18:47.133690+00:00 | restore dependency by exiting isolated fault context |
| 2026-11-20T20:18:47.212955+00:00 | three recovery probes complete |

Дія: підміна UserDataRepository.get_user_by_id винятком OSError в ізольованому
контексті unittest.mock; фізична БД відсутня. Зачеплено 5
контрольних запитів одного тестового суб'єкта. FAIL: усі 5 відповідей HTTP 500.
Тимчасовий обхід: вийти з fault context і повторити авторизовані probes; не видавати
неповний export і не перезапускати живий сервіс з RAM-даними.

Стабілізація початкового drill: 2026-11-20T20:18:47.212955+00:00; весь цикл
0.894 с. Це тривалість експерименту, не MTTR production.
Після патча: п'ять 503 з Retry-After=30 без діагностики сховища в тілі;
після повернення залежності — [200, 200, 200].
503 все одно погана availability-подія, а не повне відновлення.

SLA: [специфікація](../slo.yaml), [розрахунки](../operations/service-levels.md).
Локальна частка успіху під час ін'єкції 0/5=0%, нижча за ціль, але
**порушення 30-денного продуктивного SLA не встановлено**: немає production window.
Якщо ці 5 запитів включити в модель N, спожито 5 подій request-based budget.

regression-PASS.log, legacy-analysis.json. Коміти — git-history.json.
